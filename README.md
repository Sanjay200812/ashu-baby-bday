- **Pure Cyber-Hacking Terminal Aesthetic**: Jet black backgrounds, CRT scanlines, circuit matrix lines.
- **Neon Color Palette**: Primary terminal neon green (`#00ff66`), cyan highlights (`#00e5ff`), and red security alerts (`#ff3344`).
- **Typography**: Monospaced terminal fonts (`Fira Code`, `JetBrains Mono`, `Share Tech Mono`).

## 💻 Hidden Cyber Features & Easter Eggs

- **Hidden Command Terminal**: Press <kbd>`</kbd> / <kbd>~</kbd> or click `[ CLI ]` on the top bar:
  - `help`: Display all terminal commands
  - `status`: Live system diagnostics & modules cleared
  - `profile`: Target dossier on South Dev
  - `games`: Jump directly to arcade
  - `secret`: Decrypt hidden brotherly message from Aakash & Sanjay
  - `matrix`: Activate full-screen green digital rain
  - `clear`: Clear output buffer
  - `exit`: Close CLI session
- **Secret Data Fragments**: Collect 5 digital fragments across games to reveal the decrypted transmission in the Telemetry Dashboard!
- **Logo Easter Egg**: Click the `SOUTH DEV` title 5 times for a secret overclocking toast!
